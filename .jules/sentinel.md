## 2024-06-10 - [CRITICAL] Prevent IP Spoofing in Client IP Detection
**Vulnerability:** The `psc_get_client_ip()` function was vulnerable to IP spoofing because it prioritized and trusted user-supplied HTTP headers (`HTTP_CLIENT_IP` and `HTTP_X_FORWARDED_FOR`) over the more reliable server variable `REMOTE_ADDR`. This allowed attackers to easily bypass IP blocking and rate-limiting protections by injecting arbitrary IP addresses into these headers.
**Learning:** Client-supplied HTTP headers are untrusted input and can be easily manipulated by an attacker. Relying on them for critical security controls, such as IP blocking, without proper verification or a trusted reverse proxy configuration, introduces a significant vulnerability.
**Prevention:** For IP-based security controls, exclusively use `$_SERVER['REMOTE_ADDR']` to identify the client's IP address. Only use headers like `HTTP_X_FORWARDED_FOR` if the application is definitively operating behind a trusted reverse proxy (like Cloudflare or an internal load balancer), and ensure the proxy is configured to strip or overwrite incoming spoofed headers before appending the actual client IP.
